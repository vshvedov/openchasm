# Motion and push proposals

`motion_push::propose` is an isolated, headless first pass for translating wall segments and circular level objects while pushing players or actors. It receives a world, object circles, stable entity IDs and vertical extents, and ordered translation descriptions. It returns either cloned world/circle/entity state ready for the host to commit or a `Blocked` result identifying a pinned entity and mover. Invalid or overly large input returns an error; neither failure publishes partial movement. Entities and movers are processed in stable ID order, independent of input order.

Translations advance in simultaneous substeps of at most 1/64 tile; the proposal rejects sweeps longer than four tiles, duplicate identities, malformed geometry and inputs exceeding a bounded work budget. Each push uses the existing swept circle collision against other walls, object circles and vertically overlapping entities. A mover is excluded from its own push collision. Moving wall passability follows its supplied movement flag. Vertically separated entities are ignored for the mover contact; other geometry remains conservatively blocking when checking a push.

Initial overlaps are not resolved by stationary or retreating movers. A wall endpoint or circle can briefly graze an entity between two samples without overlapping at either sample; the solver detects that swept contact and returns `Blocked` conservatively because it cannot yet calculate a continuous-time push. Consequently `Blocked` does not always prove an entity is pinned.

This is not a complete implementation of the remaster's `CheckGo`, `CheckBack` or `Mortal`: only translation is supported, stacked entities are blocked rather than recursively pushed, static vertical geometry and materials are approximated, and the solver reports a pin without applying damage. The host must select direction-specific policies, group and publish all related state atomically, handle fixed-tick events exactly once, and synchronize runtime, networking and presentation. It is not integrated into `Session` or the process runtime.
