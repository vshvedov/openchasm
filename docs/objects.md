# Object placements and definitions

Map grid IDs 131–162 refer to an item row in `chasm.inf`'s `[3D_OBJECTS]` section; IDs 163–226 refer to a row in the level resource's `#newobjects` section. The row index is the ID minus the base of its range. Other grid IDs, including 250, are not interpreted as objects. The source game's bundled modding manual describes the ranges; [PanzerChasm's map loader](https://github.com/Panzerschrek/Chasm-Reverse/blob/master/src/map_loader.cpp) independently documents the placement interpretation used here.

Each definition contains nine numeric fields followed by a model name and optional animation name. The numeric fields are GoRad, Shadow, BMPObj, BMPz, ACode, BlowUp, BLim, Sfx, BSfx. GoRad is a collision radius in map units; the low bit distinguishes collision shapes according to the bundled manual. ACode distinguishes static objects, pickups, keys and switches. The code retains all fields without implementing their gameplay behavior. Some animation names start with `%`, which is retained as a marker and removed when deriving the resource path; playback semantics remain unverified.

Placement coordinates are the first two unsigned 16-bit coordinates in each grid record, divided by 256 for tile-space position. The low three bits of the record's flag byte encode angle in eighth turns, with the same half-turn correction used for actor spawns. The first 16-bit field in the second coordinate pair holds difficulty/game-mode flags according to PanzerChasm; the remaining field and high flag bits are retained without interpretation. Grid coordinates and actual position can differ. There is no per-instance scale field in the parsed placement. As a separate research lead, PanzerChasm's [model reader](https://github.com/Panzerschrek/Chasm-Reverse/blob/master/src/model.cpp) uses a factor of 1/2048 for 3O vertices in map tile units; this needs comparison with the installed release.

The current Steam bundle was scanned against all 20 maps. All 6,608 placements resolved to a definition and to an existing 3O or glTF model resource. There are 31 item definitions in the archive's `chasm.inf`, although the reserved range has 32 IDs; no instance of the last item ID was found. This data check does not prove compatibility with other game versions or custom content.
