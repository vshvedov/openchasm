# Static 3O preview rendering

The viewer resolves map item and level-object placements through the existing object definitions. It loads each referenced original 3O file once, applies the shared palette, and renders the placed instances with the eighth-turn angle and original model-coordinate scale recorded in [model-format.md](model-format.md). Instances retain their source grid cell so gameplay can hide a collected pickup without altering other instances using the same mesh.

The software rasterizer clips polygons against the near plane and interpolates texture coordinates perspectively. A depth buffer shared with wall pixels hides objects behind walls while permitting objects to appear through masked wall holes. It also resolves overlap between object polygons. A polygon carrying transparency-related flag bits skips skin palette index 255. Resource names that require glTF and missing or invalid 3O files are skipped with one diagnostic per resource.

This remains a preview. All objects are drawn static, regardless of animation or moving map processes. Item collection, difficulty filtering, skin replacements, glTF, sprite effects, shadows, dynamic lighting and true translucency are not implemented. Faces are currently rendered two-sided; polygon transparency flags are approximated by alpha testing. Objects are placed at height zero, and the flat floor/ceiling renderer does not yet contribute depth, so sloped or stacked geometry and polygons extending through floors can display incorrectly. Original camera height, material rules, skin offset handling, and object orientation still need direct comparison with the game.

The viewer also renders static monster placements using the first available body animation frame, the CAR model skin and CAR-specific texture coordinates. Models are cached by resource path and can be updated individually by placement index, but actors do not yet move, animate over time, attack, take damage, or obey difficulty flags. Extensionless modern-only definitions and models that cannot be resolved are skipped with a diagnostic. Visual comparison is preliminary.
