# Experimental level processes

The fixed-tick runtime handles floor-cell triggers, nearby `link` triggers via the use key, wall `move` actions, `lock` and `unlock` actions, `StartDelay`, `Speed`, `BackWait`, and circular `waitout` zones. `waitout` reverses a returning process when the player is within its radius. Wall targets use their original map grid cells, and processes can move multiple segments together.

The manual describes the commands but does not specify every timing and collision detail. Speed conversion and use range are provisional. Moving walls do not yet push or crush players, and `CheckGo`/`CheckBack` are not implemented. Other action types, speed overrides, or unresolved wall targets disable a process entirely to avoid executing only part of its behavior. Initially locked processes can be unlocked by supported switch actions; key-gated processes remain locked until inventory and key pickup are implemented. Lock changes currently occur on activation even when a start delay is set. Messages and audio are not implemented. Multiple processes affecting the same wall are not yet coordinated. `check` reports how many initially unlocked moving processes are currently supported; this is not a count of all runnable level logic.

The original level 06 file includes an action section after a commented-out process header; the parser reports it rather than silently assigning it to a different process.
